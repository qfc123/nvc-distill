# 感受与需要词汇表

溯源：第四章「体会与表达感受 · 建立感受词汇表」（感受词、伪感受黑名单）、第五章「为自己的感受负责」（普世需要 7 大类）、附录「人类共有的一些基本感受」（精简表）。中英对应关系以原书为准；本文件的编排方式、语义簇与替身索引为本仓库扩展。

## 使用规则（先读这五条）

1. **不回显全表**。用户说不出情绪词时，先给 3–5 个最接近的候选让他挑，不要甩一整张表。
2. **"好 / 坏"不合格**。它们太宽泛，无法让人明白实际状态（"感觉挺好"可能是高兴、兴奋，也可能是如释重负）。
3. **"被 X"一律不是感受**。见 §3 黑名单，必须替换成 §1 / §2 里的真感受词。
4. **口语词要更准确，但不强行换掉**：烦 → 烦躁 / 恼火；慌 → 惊慌 / 紧张；不爽 → 不快 / 懊恼。目标是帮用户把话说准，**不是把口语换成书面语**——用户自己的说法如果已经准确，就保留。
   - **"委屈"不是"难过 / 伤心 / 挫败"的替身**：它指的是"被不公平对待却无处申辩"，背后通常是**公平 / 被看见 / 被理解**的需要。**不要把它改掉**；要改的是"我觉得你让我委屈"这类把原因推给他人的句式。
5. **感受词服务于连结**，不是用来把话说得更漂亮。选词后必须能接上"因为我需要…"。

## §3 伪感受黑名单（32 条）· 必换

原书第四章原文列举。这些词出现在"我感到…"之后时，描述的是**对他人的想法或判断**，不是感受。

被抛弃 · 受到虐待 · 受到攻击 · 受到背叛 · 被陷害 · 受到霸凌 · 受到欺骗 · 受到胁迫 · 被差遣 · 被逼迫 · 被贬低 · 不受信任 · 被打断 · 受到恐吓 · 被玩弄 · 被操纵 · 受到误解 · 受到忽视 · 被挤压 · 被看不起 · 被施压 · 受到挑衅 · 被羞辱 · 被拒绝 · 不受重视 · 受到要挟 · 不受赏识 · 不被理睬 · 不被看见 · 不被支持 · 不被需要 · 被利用

**判据（原书原文）**：在"我感到 / 觉得"之后如果跟随的是**我、你、他、她、他们、它、像、好似**，通常都不是在表达感受。

替身索引（必须由 §1 / §2 选词，禁止原地保留）：

| 伪感受 | 常见误用 | 推荐替身 |
|---|---|---|
| 被抛弃 | "你一走我就感到被抛弃" | 孤单 / 害怕 / 心碎 |
| 被拒绝 | "我的提议被拒，感到被拒绝" | 失望 / 灰心 / 挫败 |
| 被误解 | "我感到被误解" | 挫败 / 灰心 / 焦虑 |
| 受到冷落 | "你没和我打招呼，我感到受冷落" | 孤单 / 伤心 |
| 不受重视 | "我说的话没人听" | 难过 / 气馁 / 沮丧 |
| 被利用 | "他们只是在利用我" | 气愤 / 苦涩 / 失望 |
| 被看不起 | "他那种语气让我感觉被看不起" | 屈辱 / 恼火 / 难堪 |
| 被施压 / 受到胁迫 | "你这是在逼我" | 紧张 / 害怕 / 憋闷（→ 烦乱） |
| 被忽视了 | "我的付出没人看见" | 失落（→ 沮丧）/ 孤单 / 气馁 |

**注意**：替身必须回到说话人自己身上。"我感到被忽视"→"我感到孤单"，而不是"你忽视了我"。
**但不得反向使用 [本仓库扩展]**：换词只改变说法，不改变责任归属。不能因为"孤单是我的感受"，就推断"所以对方做的事没关系"——感受的根源在自己，行为的责任在做事的人（见 `self-inner-work.md` §对冲条款）。

## §5 普世需要 7 大类

原书第五章原文只给出**七个分类名**，未列出子项。以下子项为 NVC 通行实践补充，**非原书列举**，使用时应以"猜测 + 求证"的方式向对方确认，不要当成标准答案。

**1. 自主选择 Autonomy** — 选择自己的梦想、目标、方向；选择自己想做的事，而非被命令。
**2. 内外一致 Integrity** — 真诚、真实、创造、意义、自我价值、言行一致。
**3. 庆祝 Celebration** — 庆祝生命的创造力与梦想的实现；纪念失去、哀悼与告别（含对遗憾的哀悼）。
**4. 相互依存 Interdependence** — 接纳、欣赏、亲密、社群、体贴、贡献、情感交流、支持、信任、理解、被看见、被听见。
**5. 精神交流 Spiritual Communion** — 美、和谐、秩序、平安、灵感、与生命本身的连结。
**6. 玩耍 Play** — 乐趣、欢笑、 spontaneity、幽默、轻松。
**7. 滋养身体 Physical Nurturance** — 空气、水、食物、休息、睡眠、运动、身体接触、安全、免受伤害。

**需要 vs 策略的硬判据**：需要是普世的、不指向任何特定行动；一旦带上"让某人做某事"（离婚、加薪、今晚陪我），就已经是策略，不是需要。

## §6 中文高频感受词 · 语义簇速查（本仓库扩展）

原书词表按英文首字母排列，中文使用者检索不便。以下按中文语境的使用频率重组，仅在需要快速定位时使用，词条仍出自 §1 / §2。

| 语义簇 | 满足时 | 未满足时 |
|---|---|---|
| 亲密与连结 | 温暖、亲近（深情）、触动、柔软 | 孤单、疏离（抽离）、心碎、哀痛 |
| 被看见与被认可 | 自豪、受鼓舞、欣慰、心满意足 | 气馁、沮丧、灰心、难堪（惭愧） |
| 掌控与确定 | 自信、镇静、安心（安全）、笃定（满足） | 焦虑、担心、紧张、迷茫、不知所措（困惑） |
| 自主与自由 | 自在、轻松（无忧无虑）、活力（有活力） | 憋闷（烦乱）、受困（拘谨）、厌倦、被动 |
| 公平与尊重 | 感激、信任（满怀信任）、平和（平静） | 气愤、恼火、屈辱、愤恨、敌对 |
| 节奏与负荷 | 放松、清爽（神清气爽）、轻盈（快活） | 不堪重负（紧绷）、精疲力竭、倦怠、急躁（不耐烦） |
| 期待与希望 | 满怀希望、期盼、惊喜、乐观 | 失望、幻灭、绝望、无望（悲观） |
| 好奇与意义 | 好奇、着迷、受启迪、振奋（激励） | 无聊、乏味、麻木、空洞（沉闷） |

用法：先定语义簇，再回到 §1 / §2 挑一个最贴切的具体词。不要用簇名本身当作感受词（"我感到亲密"不是感受，"我感到温暖"才是）。
