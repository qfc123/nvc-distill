# 四要素引擎 · 表达与倾听

溯源：第一章「非暴力沟通过程」（四要素的提出）、第三章（观察）、第四章（感受）、第五章（需要）、第六章（请求）。

## 引擎本身

非暴力沟通把注意力聚焦在四个方面，它们是同一个引擎的四个要素 **[第一章]**：

1. **观察** — 实际发生了什么。不论喜欢与否，只说出人们做了什么，不夹杂评判。
2. **感受** — 看到这些行为时的感受：伤心、害怕、喜悦、有趣，还是心烦。
3. **需要** — 这些感受与什么需要相关联。
4. **请求** — 希望对方做什么来让我们的生命更美好。

原书示范（第一章）[本仓库缩写]：一位母亲对青春期的儿子说："菲利克斯，看到咖啡桌下的两团脏袜子和电视机旁边的三团脏袜子，我很生气，因为我希望在我们共用的空间里能多些整洁。你愿意把你的袜子放在你房间或放进洗衣机里吗？"

**两个方向，同一引擎 [第一章]**：
- **表达自己**：我观察…我感到…因为我需要…你是否愿意…？
- **倾听他人**：从对方的话里感知他此刻的观察、感受、需要，再听见他的请求。

**不是固定公式 [第一章]**：可根据情境、个人和文化习惯调整，甚至无须借助言语。精髓在于对四个要素的觉察，不在于具体说了什么。四个要素的顺序、是否全说，都服务于连结这一目的。

## 四个区分（最常出错，逐条守住判据）

### 1. 观察 vs 评论 [第三章]

- **观察**：清楚地观察哪些所见、所闻、所触正影响着我们的幸福，不夹杂任何评论。
- **评论**：标签、推断、一概而论。
- 非暴力沟通**不要求保持完全客观**，只要求**区分**观察与评论。它不鼓励一成不变、一概而论的陈述。
- 陷阱词：`总是 / 从不 / 每次 / 经常 / 又 / 依然`。描述具体事件时可以是观察，一旦用来定性就是评论。
- 改写：
  - ✗ "汉克是名糟糕的足球运动员" → ✓ "汉克在过去 20 场球赛中未进一球"
  - ✗ "我父亲是个好人" → ✓ "过去 25 年，我父亲将收入的十分之一捐给了慈善"
- 原书引用（克里希那穆提）："不带评论的观察是人类智力的最高形式。"

### 2. 感受 vs 想法 [第四章]

- **真感受**：具体的情绪词，不用模糊的"好 / 坏"（"感觉挺好"可能是高兴、兴奋，也可能是如释重负）。
- **伪感受**：在"我感到 / 觉得"之后跟随的是**我、你、他、她、他们、它、像、好似**，通常都不是在表达感受。
- 三类常见混用 **[第四章原文分类]**：
  1. "我感到"后加一句话或"就像 / 好似"——"我觉得自己就像个失败者"
  2. "我感到"后带人称——"我觉得自己一直在被使唤"
  3. "我感到"后加他人名称或名词——"我觉得我的上司很爱控制人"
- 改写：
  - ✗ "我觉得我就像嫁给了一堵墙" → ✓ "我感到孤单，想和你有更多情感上的交流"
  - ✗ "我感到被误解" → ✓ "我感到挫败 / 我很灰心"
  - ✗ "我很没用" → ✓ "想到我的能力，我感到怀疑 / 苦恼"
- 完整词表与替身索引见 `feelings-needs-vocab.md`。

### 3. 需要 vs 策略 [第五章]

- **需要**：普世共通，不指向任何特定行动。
- **策略**：某人采取的某个具体行动（离婚、加薪、今晚陪我都是策略，不是需要）。
- 原书观察 **[第五章]**：人们在冲突中更善于分析对方的错，而非清晰地表达需要。一旦开始谈论需要而非相互指责，就更有可能找到满足大家的办法。
- 说出需要的障碍 **[第五章]**：袒露需要会遭到强烈评判，因而害怕表达。常见替代形式是"辩护词"——先罗列自己做了多少事，再近乎哀求地提出请求，这反而使对方心生抗拒。直接说出需要，更可能获得积极回应。

### 4. 请求 vs 要求 [第六章]

- **判据**：看对方没有答应时我们的反应。指责 = 要求；同理 = 请求。
- 原书示范 **[第六章]**：杰克说"我感到很孤单，你今晚能来陪我吗？"珍妮说"我今天很累"。杰克若回"你就是这样自私"，那是要求；若回"你的意思是你已经很累了，今晚需要休息？"，那是请求。
- "在听见要求时，一个人通常只能看到两种选择：屈服或者反抗。"
- 选择请求**不等于对方说不就放弃诉求**，而是先同理他为什么没有说"是"，而不是说服他必须答应。
- 表明自愿：用"你是否愿意铺一下桌子？"而非"我想要你铺一下桌子"。
- 权力提示 **[第六章]**：处于权力强势一方时，对方（尤其曾受权威压迫者）更容易把请求听成要求，需要额外说明意图。

## 请求的三条硬标准 [第六章]

1. **正向语言** — 说要什么，不是不要什么。
   - ✗ "我希望你不要花那么多时间在工作上" → ✓ "我希望你每周至少有一个晚上在家陪我和孩子"
   - 原书理由：负向请求让人搞不清到底要做什么，且容易引发抗拒。
2. **具体可行** — 避免模糊、抽象、模棱两可。
   - ✗ "希望得到公正的对待"（校长会立刻否认自己不公正）→ ✓ 学生列出希望校长做到的 38 件具体事项，校长全部同意
   - ✗ "我希望你给我自由，让我做自己" → 多半是在掩盖操控意图
   - ✗ "希望你有责任感" → 真正的意思常常是"听我的话"（那是顺从，不是责任感）
   - ✗ "尊重我的隐私" → ✓ "进我房间前先敲门"
3. **此刻可回应** — 用"你是否愿意…？"，让对方当下能给出回应。

## 请求的配套动作（常被忽略）

- **请对方重述你的话 [第六章]**：我们的本意和他人的理解有时是两回事。请求对方复述，以便在有误解时修正。先说明目的——不是测试对方的聆听能力，而是核实自己是否表达清楚。若对方反应激烈（"你觉得我是聋子吗"），继续同理他这句背后的感受与需要。
- **请求诚实表达 [第六章]**：表达完并确认对方听懂后，明确说出想听哪一类回应——（1）对方听到这些话的感受及原因；（2）对方的想法；（3）对方是否愿意采取某个行动。
- **有意识地提出请求 [第六章]**：很多人说话时并不知道自己想要什么。三类常见的真实诉求：期待对方的理解与连结 / 请求坦诚回应 / 请求对方采取某种行动。越是清楚自己想要什么，越能实现所想。
- **先说感受与需要再提请求 [第六章]**：只提请求、不先表达感受与需要，容易被听成要求或指责。
  - ✗ "你为什么不去理发呢？" → ✓ "我们担心你的头发太长会遮住视线，特别是骑自行车的时候，你要不要去理个头发呢？"
- **阐明提出请求的目的 [第六章]**：若目的只是改变他人来谋求自己的利益，非暴力沟通并不是适当的工具。它的意图是建立基于坦诚与同理心的关系。

## 表达后的两个确认动作

见上"请对方重述"与"请求诚实表达"。二者共同解决一个问题：我说的话 ≠ 对方听到的话。

## 关键提醒

- **意图决定一切 [第六章]**：机械使用四要素而没有连结意图，等于失败。是否成功的判据不是"请求有没有被满足"，而是连结有没有建立。
- **翻译自己的话时，第一步常是先识别豺狗语言**（见 `anti-patterns.md`），再译成四要素。
- **NVC 不要求对方也懂它 [第一章]**：只要我们遵循原则、发自内心地给予，并让对方知道这是唯一动机，对方也会逐渐加入。
