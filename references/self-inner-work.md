# 爱自己 · 内在工作

溯源：第五章「为自己的感受负责」（四种选择、情绪自由三阶段）、第九章「爱自己」（哀悼、自我宽恕、不得不→我选择、行为动机）、第十三章「解放自我，协助他人」（用非暴力沟通取代诊断）。

## 听到不中听的话的四种选择 [第五章]

他人的言行或许会**激发**我们的感受，但绝非产生这些感受的**原因**。感受源自我们如何看待他人的言行，以及我们当时的需要和期待。

| 选择 | 做法 | 典型感受 |
|---|---|---|
| 1 指责自己 | 把错误归咎到自己身上："哦，我应该更体贴一点" | 内疚、羞愧、压抑，自尊受损 |
| 2 指责他人 | 把错误归咎到对方身上："你没有资格这么说！" | 愤怒 |
| 3 **关注自己的感受与需要** | "我感到伤心，因为我渴望得到认可" | 伤心等真实情绪，可导向行动 |
| 4 关注对方的感受与需要 | "你感到伤心，希望你的喜好能得到照顾，是吗？" | 连结 |

处理自己的情绪与决策时：**先用第 3 项**，必要时再用第 4 项。

## 为自己的感受负责：三类掩盖责任的语言 [第五章]

1. **用非人称代词**："手册有拼写错误，**这**让我非常生气" → "看到手册有拼写错误，我感到非常生气，因为我希望公司呈现出专业的形象"
2. **"我感到X，因为（别人）…"**："我感到愤怒，因为上司不守信用" → "当上司违背了承诺，我感到愤怒，因为我原本希望用那个长假探望哥哥"
3. **只提及他人的行为**："你没把食物吃完，妈妈感到失望" → "你没把食物吃完，妈妈感到失望，因为我希望你身体强壮、健康成长"

统一替换为"**我感到……因为我……**"的句式。

**不要用内疚推动他人**："你成绩不好，让爸爸妈妈伤透了心"——孩子为了父母感受而改变，动机只是避免愧疚，而非出自真心。

## 需要：感受的根源 [第五章]

评判、批评、分析或判断他人的言行，实际上是在用疏离生命的方式**表达自己的需要**：
- "你从不懂我" → 渴望得到理解
- "这星期你每天都工作到很晚，相比我，你更爱工作" → 亲密的需要未得到满足

## 情绪自由三阶段 [第五章]

成长的三个阶段：

1. **情绪的奴隶** — 认为自己要为他人的感受负责，把亲近的人当成负担。
2. **面目可憎** — 拒绝为他人的感受负责，"这是我的事，不关你的事！"——已经知道不必为他人负责，但还没学会不带敌意的表达方式。原书态度：能冒着得罪人的危险表达需要，本身就是进步，值得庆祝。
3. **情绪的主人** — 全然地为自己的感受负责，同时意识到**牺牲他人的福祉也无法满足自己的需要**；发自慈悲而非恐惧、内疚、羞愧地回应他人。

## 哀悼与自我宽恕 [第九章]

**为什么不要自我评判**：被教导"好坏对错"的人会用指责对待自己（"笨蛋！""你总是把事情搞砸！"）。这样的方式只会陷入自我憎恨，无法从失误中学习。即使因此改变，背后的驱动力也是破坏性的。

- "应该"这个词充满暴力，暗示别无选择；人天生抗拒被"应该"支配——不论来自外在强权还是内在暴君。

**哀悼（mourning）** [第九章]：
- 觉察自我评判 → 停下来问："我这样指责自己，是因为什么需要没有得到满足？"
- 充分连结未被满足的需要，以及因自认为做得不够完美而引发的感受。
- "哀悼，让我们不再以指责或怨恨自己的方式来经验后悔，而是帮助我们从中学习。"
- 关键区分：**难过、挫败、失望、恐惧、悲伤**是与生俱来的感受，目的是推动我们去满足需要；**内疚、羞愧、压抑**会切断我们与自己的连结。

**自我宽恕** [第九章]：
- 问："我当时那样做，是要满足什么需要呢？"
- 人的行为都是为了满足需要所做的尝试，不论是否实现了目的。
- 带着同理心拥抱两个"自己"：对过去行为感到懊恼的自己 + 当初做了那件事的自己。

原书案例（圆点外衣，本仓库缩写）：马歇尔把没盖笔套的钢笔插进新衣口袋，毁了一件新外衣，自责 20 分钟后问自己"我指责自己粗心，是出于什么需要" → 需要是"好好照顾自己"。随后又问"我那样做是要满足什么需要" → 关心和体贴别人。怒气与羞愧消散，转而升起对自己的疼爱。

## "不得不"转化为"我选择" [第九章]

三步练习：

1. 列出生活中**无趣却又认为不得不做**的事。
2. 在每一件前面加"**我选择做……**"，明确告诉自己这是选择而非义务。
3. 补全"**我选择做……因为我想要……**"，连结背后的需要。

原书结果（本仓库缩写）：马歇尔发现自己写临床报告的唯一动机是收入，于是停写（用别的方式赚钱）；继续开车送孩子上学，因为看见自己重视教育品质——同样是送，心态完全变了。

## 觉察行为动机的 6 类来源 [第九章]

检视一个行为是否被下列动机驱动：

| 动机 | 原书要点 |
|---|---|
| 1. 为了钱 | 金钱不是"需要"，而是满足某个需要的策略之一。纯粹为钱而做的选择代价高昂——会失去生活的乐趣 |
| 2. 为了得到他人的认可 | 与金钱同为外在奖励。我们如饥似渴地追求微笑、拍背、"好人 / 好员工"的标签，像上瘾一般。**如果行动只是为了丰盈生命，人们自然会来欣赏我们** |
| 3. 为了免受惩罚 | 原书对照：有人纳税只为免罚，因而心怀抵触；作者的父辈经历沙皇统治后，想到税金能让他人获得福利，满怀喜悦地寄出支票 |
| 4. 为了避免羞愧 | 只因不想被自己抨击而做的事，通常以厌恶此事告终 |
| 5. 为了免于内疚 | "如果我不做，别人会失望"。为避免内疚而做，苦不堪言；为对他人的幸福做贡献而做，充满乐趣 |
| 6. 为了履行职责 | 用"应该 / 不得不 / 应当 / 必须 / 不能 / 理应"描述行动时，驱动我们的是义务感，而非与需要的连结 |

**核心判据**：出于对生命纯粹的爱而行动，即使工作辛苦也会乐在其中；出于恐惧、内疚、羞愧、义务或职责，即使有趣的事也会失去乐趣，最终让人心生抗拒。原书立场："**不做任何没有乐趣的事**。"

## 用非暴力沟通取代诊断 [第十三章]

- 不再探讨"对方有什么问题"，转而关注：**他现在的感受是什么？他需要什么？面对他，我有什么感受？我的感受反映了什么需要？我想请求他做什么使他过得更幸福？**
- 这些回答透露的是我们的内心世界与价值观，因此比诊断他人更让人感到脆弱——但也因此更真诚。
- 原书观察：一旦不再试图诊断、分析人，而是把内心世界与对方连结，人们通常会给予积极回应。
- 辅导关系的目标：创造**真诚、坦率和双向**的关系，而不是保持情感距离、诊断对方，或摆出高高在上的专业姿态。
- **本仓库扩展边界**：本 Skill 不做心理诊断、不替代治疗。涉及重性精神障碍、成瘾、自伤风险时转介专业机构（见 `safety-boundaries.md`）。

## 自我侧常见翻车点

- 把"我选择做…因为我想要…"做成口号，却没真的连结到需要。
- 用内疚驱动改变（"我应该更努力"），短期有效、长期耗竭。
- 哀悼停在自责里，没有走到"我当时想满足什么需要"。
- 把"不为他人感受负责"执行成冷漠（停在"面目可憎"阶段）。
- 用"需要"包装策略："我需要你今晚陪我"——陪是策略，需要可能是连结或安心。
