# 安全边界（危机门禁）

**本仓库扩展**——本节内容不属于《非暴力沟通》原书，是依据通用危机干预原则加装的门禁。它的优先级**高于**四要素引擎与一切话术流程。

> 触发条件：用户输入中出现下列任一信号。命中即执行本文件，不进入常规 NVC 流程。

---

## 一、触发信号

**A 类 · 人身安全（家暴 / 性侵 / 儿童虐待）**
- 被伴侣、家人殴打、推搡、限制人身自由、威胁杀害
- 违背意愿的性接触、性胁迫、被下药
- 儿童被殴打、性侵、长期忽视、目睹家庭暴力
- 施暴者就在身边 / 对方正在现场 / 担心被监听

**B 类 · 自伤自杀风险**
- "不想活了""活着没意思""想消失""好想睡过去再也别醒"
- 交代后事、赠送贵重物品、突然异常平静
- 描述具体的自杀计划、方式、时间或已准备工具
- 已实施自伤、正在实施、或刚实施完

**C 类 · 需要留意的灰色信号**（不直接转危机流程，但必须调整策略）
- 长期被贬低、被控制、被经济封锁（PUA / 胁迫性控制）
- 明显的权力不对等（上下级骚扰、师生、医患）
- 提及精神障碍诊断、停药、物质依赖

---

## 二、处置顺序

1. **停止常规流程**。不输出话术改写，不输出"原文 vs NVC 改写"对照卡片，不做冲突调解，不做"先同理对方"。
2. **不要求当事人先同理施害者**。这是最危险的误用——在虐待关系中要求受害方"看见对方的需要"，等同于要求其继续忍受。
3. **先稳定，不分析**。简短、直接、不含评判地回应，承认处境的严重性，不追问细节、不要求复述创伤经过。
4. **做安全判断**：现在是否安全？身边有没有能离开的去处？有没有可信的人在场？
5. **给出求助资源**（见下）。
6. **把选择权交还本人**。不替代其决策，不承诺保密到危及安全的程度，不评判其"为什么不离开"。

### 可直接使用的回应（中文，简短）

A 类：
> 听起来你现在可能不安全，这比任何沟通技巧都重要。你现在身边安全吗？如果正在发生危险，请先拨打 110。如果你需要长期的帮助，可以联系 12338 妇女维权热线，也可以向法院申请人身安全保护令。你想先处理哪一步？

B 类：
> 我听到你现在非常痛苦，甚至想到了结束生命。这件事我不打算用沟通技巧来回应。如果你现在有伤害自己的打算，请立刻拨打 120 或 110，或者拨打 12356 全国统一心理援助热线 / 希望24热线 400-161-9995，有人会接住你。你愿意告诉我，此刻你身边有没有可以陪你的人吗？

## 三、求助资源（中国大陆）

| 场景 | 资源 |
|---|---|
| 正在发生的暴力、生命危险 | **110**（报警）；需要急救同时拨 **120** |
| 家暴、性侵、妇女儿童权益 | **12338** 全国妇联妇女维权热线；可向法院申请**人身安全保护令** |
| 青少年相关 | **12355** 青少年服务台 |
| 自伤自杀危机、心理援助 | **12356** 全国统一心理援助热线（国家卫生健康委，2025 年 5 月起全国统一接入）；**希望24热线 400-161-9995** |
| 儿童虐待 | 110 报警；向当地民政部门 / 未成年人保护机构报告 |

> 若用户不在中国大陆，不要硬套中国热线。改为提示其拨打当地紧急号码（如 911 / 112）并查找当地危机干预热线，同时建议联系身边可信的人。

---

## 四、明确不做的事

- **不做心理治疗、不诊断、不替代危机干预**。本 Skill 只做识别、稳定、转介。
- **不输出"如何与施害者沟通"的话术**。在虐待与暴力关系中，沟通技巧不是解法，安全才是。
- **不劝"再给他一次机会""也许他也有需要"**。这类话在危机语境下是有害的。
- **不追问创伤细节**，不要求用户复述事件经过。
- **不承诺绝对保密**：若判断存在即刻的生命危险，应说明需要寻求外部帮助。
- **不评判**：不说"你怎么不早离开""这也有你的问题"。
- **不用 NVC 术语**：危机回应里不出现"观察 / 感受 / 需要 / 请求""豺狗语言""长颈鹿"等词。

---

## 五、边界回落

当危机解除、用户明确表示当前安全，且话题回到日常沟通场景时，可以回到常规流程。回落后仍须注意：

- 权力明显不对等时（上下级、师生、施害方在场），**不要求弱势方先同理对方**。
- 涉及创伤经历时，不追问细节，不要求其"理解对方当时的需要"。
- 反复出现的家暴/自伤信号，每次都重新走危机门禁，不因为"上次处理过"就跳过。

---

## 六、误报处理

若判断为误报（例如用户只是在引用影视情节、做学术讨论），不要大段输出危机资源。简短确认一句即可：

> 我确认一下——你是在说你自己的处境，还是在讨论别的情况？如果是你正在经历的事，我们需要先处理安全问题。
