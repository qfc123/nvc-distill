# 七大应用领域

溯源：第一章「非暴力沟通的运用」原文列举了七个领域：亲密关系、家庭、学校、组织与机构、心理辅导与咨询关系、外交与商业谈判、任何性质的纠纷与冲突。

**本仓库扩展说明**：原书只列出领域名并配了若干学员来信作为佐证，未给出逐领域的原则与句式。以下每域的"典型暴力形态 / 第一原则 / 起步句式 / 翻车点"四段为本仓库依据全书方法推演，**不是原书原文**。使用时以四要素引擎为准，本表只用于快速定位发力点。

---

## 1. 亲密关系

- **典型暴力形态**：把对方的行为解读成"爱不爱我"的证据；用冷战惩罚；拿对方与前任或理想伴侣比较；"你从来都不…"
- **第一原则**：先连结后方案。需要长期处于未说出状态，才累积成"你不懂我"的定论。
- **起步句式**："这周有三个晚上你都在加班，我感到孤单，因为我需要情感上的连结。你是否愿意这周六晚上我们一起吃饭，不看手机？"
- **翻车点**：把"我感到孤单"说成"你根本不在乎我"；把某个具体安排（周六吃饭）当成需要本身。

## 2. 家庭（亲子 / 代际）

- **典型暴力形态**：道德评判式的管教（"你怎么这么懒"）、体罚与羞辱、用内疚驱动（"你让爸妈伤透了心"）、拿别人家孩子比较
- **第一原则**：把目标从"服从"换成"参与"。区分保护性强制力与惩罚性强制力——危险迫在眉睫时用前者，事后教育绝不用后者。
- **起步句式**："看到你把袜子扔在客厅（观察），我有些烦躁（感受），因为我需要共用空间的整洁（需要）。你愿意把袜子放进洗衣篮吗（请求）？"
- **翻车点**：用"应该""你必须"开场；孩子拒绝后立刻指责（那说明提的是要求）。

## 3. 学校

- **典型暴力形态**：贴标签（"问题学生""多动症"）、当众羞辱、用评分与处分作为威胁
- **第一原则**：把注意力从"这个学生有什么问题"转到"他现在需要什么"。原书佐证：特殊教育班级里，一个会吐口水骂人的孩子在被引导后说出"当你靠我那么近时，我感到生气。可以请你离我的桌子远点吗？"
- **起步句式**："你刚才推了同学，我担心有人受伤。你当时是想要…吗？"
- **翻车点**：把诊断标签当成解释；以为非暴力沟通等于放任不管（原书专门区分过二者——不干预会让秩序失控，保护性强制力仍需使用）。

## 4. 组织与机构

- **典型暴力形态**：层级话语即命令；用惩罚与考核施压；把下属的表达听成挑战
- **第一原则**：层级关系下**先安全感后请求**。原书提醒：处于权力强势一方时，对方更容易把请求听成要求，需要额外说明意图。上行同理也同样重要——听到上司的话时先听见其背后的需要（如"别牵扯进处理不了的事""别影响教学任务"），再表达自己。
- **起步句式**："这个项目已经延期两次，我有些焦虑，因为我需要对交付节奏有把握。你是否愿意每周三同步一次进度？——这是请求不是要求，如果你有困难，我想先听听你的顾虑。"
- **翻车点**：用"希望大家有责任心""要有主人翁意识"这类抽象词；把请求包装成通知。

## 5. 心理辅导与咨询关系

- **典型暴力形态**：诊断与分类；保持情感距离的"专业姿态"；用理论套人
- **第一原则**：**用非暴力沟通取代诊断**。关注"他现在的感受是什么 / 他需要什么 / 面对他我有什么感受 / 我的感受反映了什么需要 / 我想请求他做什么使他过得更幸福"。
- **起步句式**："听你说这些，我猜你感到很疲惫，因为你希望能有人真正听懂你——是这样吗？"
- **翻车点**：用专业术语挡住真实接触；把对方的沉默当成阻抗而非信息。
- **边界**：本 Skill 不做诊断、不替代治疗。涉及重性精神障碍、成瘾、自伤风险须转介（见 `safety-boundaries.md`）。

## 6. 外交与商业谈判

- **典型暴力形态**：把对方定性为"不可理喻的一方"；用"分析对方的错"代替"表达自己的需要"；追求妥协而非满意
- **第一原则**：先让双方听见彼此的需要，再谈策略。原书观察：冲突一开始人们更善于分析对方的错（"他们就是一群种族歧视分子"），会谈只会更糟。
- **起步句式**："我想先确认我理解对了：贵方最在意的是交付的确定性，对吗？我们的需要是成本的稳定性。我们来看看有没有同时满足两者的做法。"
- **翻车点**：把对方说的"不"当成拒绝；急于进入方案而跳过需要澄清。

## 7. 任何性质的纠纷与冲突

- **典型暴力形态**：分析、诊断、暗示对方有错；要求对方让步；诉诸第三方权威压制
- **第一原则**：连结优先，满意而非妥协。按 `anger-conflict-force.md` §化解冲突五步骤推进。
- **起步句式**："我先说我的需要：…。你呢，你在这件事上最看重的是什么？"
- **翻车点**：用"聆听""尊重""让我做自己"这类模糊词提策略；调解人下场站队。

## 领域差异速查

| 领域 | 最容易踩的坑 | 最先要做的动作 |
|---|---|---|
| 亲密关系 | 把行为解读成爱与不爱的证据 | 说出长期未说的需要 |
| 家庭 | 用内疚与惩罚驱动 | 区分保护性 vs 惩罚性强制力 |
| 学校 | 贴标签、放任不管 | 从"他有什么问题"转到"他需要什么" |
| 组织 | 请求被听成要求 | 额外说明意图，先安全感 |
| 咨询 | 诊断取代连结 | 用 NVC 取代诊断 |
| 谈判 | 分析对方的错 | 先澄清双方需要 |
| 纠纷 | 追求妥协 | 连结优先，找满足各方的策略 |
