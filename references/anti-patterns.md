# 反模式：疏离生命的语言（豺狗语言）

溯源：第二章「疏离生命的语言」。原书指出这类语言与表达方式造成人们对自己和他人的暴力；它植根于性恶论与等级制（或霸权）社会，既源于此又反过来巩固它。

识别它们是翻译成四要素的第一步。

---

## 五大主形态

### 1. 道德评判

当他人的行为与我们的价值观不符，就认为这个人是错的或恶的。形式包括：**指责、侮辱、贴标签、批评、比较、分析**。

- 例："你的问题就是太自私了" / "她很懒" / "他们有偏见" / "这样做不恰当"
- 实质：评判是在用**悲剧性的方式**表达自身的价值观和需要，引发对方的防卫与抗拒。就算对方遵从了，也多是出于恐惧、内疚或羞愧，而非发自内心——两败俱伤。
- **关键区分**：**价值判断** ≠ **道德评判**。
  - 价值判断（可保留）：珍视诚实、自由、和平——反映我们的信念。
  - 道德评判（要替换）：指责不符合这些价值观的人。
  - 改写示范（原书原文）：把"暴力是不好的，杀人者很邪恶"改为"对于通过暴力来解决冲突，我很担心，我希望能选择其他方式来化解纷争"。
- 原书佐证：道德评判类词语使用频率越高，暴力事件越频繁；在关注需要的文化中，暴力事件少很多。

### 2. 做比较

拿自己或他人与某个标准比较，切断对人对己的善意。原书借《如何让自己活得很悲惨》的练习说明：**一旦开始比较，就会感到郁闷**——先比身材，再比成就（拿自己和莫扎特 12 岁时的成就比）。

### 3. 推卸责任（否认选择）

每个人都对自己的思想、情感与行为负有责任；意识不到这点，沟通就会疏离生命。两个典型话术：

- **"不得不"式**："有些事不管你喜不喜欢，都不得不做"
- **"让人感到"式**："你让我感到内疚"

**推卸责任的 8 类话术（原书第二章逐条列举）**——每条配一句典型话术与一句转化：

| 归咎对象 | 典型话术 | 转化为"我选择…因为我想要…" |
|---|---|---|
| 模糊的外部因素 | "我打扫房间，因为我不得不做" | 我选择打扫，因为我想要整洁的居住环境 |
| 个人状况、医疗诊断结果、身体或心理病史 | "因为我有酒瘾，所以我喝酒" | 我选择喝酒，因为我想要缓解当下的痛苦 |
| 他人的行为 | "我的孩子冲上马路，所以我才会打他" | 我选择打他，因为我想要他下次不再冒险 |
| 权威的命令 | "我欺骗客户，因为老板叫我这么做" | 我选择照做，因为我想要保住这份工作 |
| 群体压力 | "朋友都抽烟，所以我也开始抽烟了" | 我选择抽烟，因为我想要被这个群体接纳 |
| 机构政策、章程、规定 | "我不得不勒令你停学，这是学校制度" | 我选择执行这条规定，因为我想要保住职位 / 维持秩序 |
| 性别角色、社会角色或年龄角色 | "我厌恶上班。我去工作，因为我是一名丈夫和父亲" | 我选择上班，因为我想要供养这个家 |
| 无法抑制的冲动 | "我一时没克制住，就把那根棒棒糖给吃了" | 我选择吃掉它，因为我想要那口甜味 |

**艾希曼"军官语言" [第二章]**：被问为何采取某个行动，答"我不得不那么做"；追问为何"不得不"，答"上级的命令""公司政策""法律规定"。当语言否认了个人选择，人就与自己失去连结而沦为机器。

**完整的转化练习**见 `self-inner-work.md` §"不得不→我选择"。

### 4. 强人所难的要求

以"要求"表达诉求，即不配合就（明或暗）指责或惩罚。特别常见于掌握权力地位的人。

- "在听见要求时，一个人通常只能看到两种选择：屈服或者反抗。"
- 判据与改写见 `engine-four-components.md` §请求 vs 要求。

### 5. 奖惩思维 / "应该""活该"

相信有的行为该受奖赏、有的该受惩罚。常用"活该"表达："他活该为自己的所作所为受到处罚"。

- 隐含假设：做错事的人是"坏人"，应当受罚、忏悔、改变。
- 原书立场：**所有人都渴望改变，是因为明白改变能为自己带来益处，而不是因为不想受到惩罚。**
- 语言线索：`错误 / 应该 / 不得不 / 应当 / 必须 / 不能 / 理应`——这些词暗示别无选择，会让人习惯向外、向权威寻求判断标准。

## 场景衍生反模式

**沟通 / 同理场景**
- **伪感受**："我感到被X"（被忽视 / 被误解 / 被冷落 / 被抛弃 / 被利用…）——是想法或评判，不是感受。完整名单见 `feelings-needs-vocab.md` §3。
- **用安慰、建议、说教代替同理**：急着搞定问题反而阻断连结。完整清单见 `listening-empathy.md` §妨碍同理的行为。
- **机械套用四要素**：走流程而无连结意图，或借四要素之名行改变他人之实。

**冲突 / 管教场景**
- **惩罚性强制力**：打骂、羞辱、剥夺关爱，让人吃苦头悔改。代价与局限见 `anger-conflict-force.md`。
- **妥协式解决**：各退一步、无人真正满意（NVC 要的是"满意"而非"妥协"）。
- **分析 / 诊断对方**："你没有责任感""你无动于衷"——会被听成批评，升级冲突。

**赞赏场景**
- **评判式赞美 / 用表扬操控**：正向评判同样属于疏离生命的沟通。替代方案见 `voice-and-gratitude.md`。

## 快速自检信号

拿到一段话，逐条扫：

1. 有没有给人贴标签或定性？（"懒""自私""不负责任"）
2. 有没有"总是 / 从不 / 每次 / 经常 / 又 / 依然"？（用于定性即为评论；描述具体事件时可以是观察）
3. 有没有"被X"式伪感受？
4. 有没有"不得不""你让我""这是规定"？
5. 有没有"你应该 / 你不应该"？
6. 说的是"不要做什么"还是"要做什么"？
7. 有没有把某个具体行动（策略）说成了需要？

命中任意一条，先标记出来，再逐条译成四要素。**例外 [本仓库扩展]**：用户处在快速档（只要一句回复、或正在倾诉求安慰）时，**不要**当场做这轮自检——先给能直接说的话。档位判据见 `SKILL.md` §交付契约。
