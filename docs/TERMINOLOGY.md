## 易混词对照（必须区分）

| 容易混用 | 正确用法 |
|---|---|
| 需求 / 需要 | 统一用 **需要**（Need） |
| 共情 / 同理 | 统一用 **同理**（empathy）；"同情"是另一回事，属妨碍同理的行为 |
| 观察 / 事实 | 统一用 **观察** |
| 请求 / 诉求 | 统一用 **请求**；"诉求"偏策略语境 |
| 策略 / 解决方案 | 统一用 **策略** |
| 评判 / 判断 | 道德**评判**（要替换）；价值**判断**（可保留） |
| 难过 / 委屈 | **不是同义词，不可互相替换** [本仓库扩展]：**委屈** = 被不公平对待且无处申辩（需要通常是公平、被看见）；**难过** = 一般性伤心。改写时**保留"委屈"**，要改的是"你让我委屈"这类把原因推给他人的句式 |

## 外部依据来源词（非原书术语，来自 [外部依据·WHO]）

| 词 | 含义 | 边界 |
|---|---|---|
| 心理虐待 / 精神暴力 | 长期贬低、羞辱、威胁、恐吓 | WHO 用词，不属于原书术语体系；不与保护性 / 惩罚性强制力混用 |
| 控制性行为（胁迫性控制） | 隔绝亲友、监视行踪、限制获得经济资源 / 就业 / 教育 / 医疗 | 同上 |
| 经济控制 / 经济虐待 | 控制工资卡、不给生活费、阻止上班或上学、要求逐笔报账 | 同上；本仓库早期用"经济封锁"，统一改用本表用词 |

> `心理虐待` / `控制性行为` / `经济控制` / `经济虐待` 四个词**只在 C1（亲密伴侣或家庭成员之间的控制与虐待）语境下使用**。C2 权力不对等不得使用"控制和虐待"的措辞。

## C 类三个子类的命名与依据边界 [本仓库扩展]

| 子类 | 名称 | 依据标签 | WHO 是否覆盖 |
|---|---|---|---|
| **C1** | 控制与虐待 | `[外部依据·WHO]` | **是**（WHO 定义对象为**亲密伴侣暴力 IPV**） |
| **C2** | 权力不对等 | `[本仓库扩展]` | 否 |
| **C3** | 诊断、用药与物质依赖 | `[本仓库扩展]` | 否 |

> 同时命中多个子类时按最重处理：**C1 > C2 > C3**。任一子类叠加 A / B 类信号 → 按 A / B 类处理。

## 中文禁用表达（伪感受）

"被X"式一律不算感受：被抛弃 / 被拒绝 / 被误解 / 被忽视 / 被利用 / 被看不起 / 不受重视 / 受到冷落 / 受到胁迫 …（完整 32 条见 `references/feelings-needs-vocab.md` §3）
