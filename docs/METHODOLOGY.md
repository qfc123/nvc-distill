## 0 · 一句话：把注意力从对错转回到需要

非暴力沟通（NVC）不是"好好说话的技巧"，而是一种**注意力训练**：把注意力从"谁错了"转回到"有什么需要没有被满足"。

- 借用甘地的"非暴力"一词，指代**当暴力从心中消融，天性中的善自然呈现的状态** [第一章]。
- 慈悲（compassion）= com（共同）+ passio（苦痛）= **与苦痛同在**。
- NVC 并非新知，它整合的是人们早已知晓的东西：人与人相互连结是人的天性 [第一章]。
- 原书用一个比喻说明它的作用：一个人在路灯下找钥匙，不是因为钥匙丢在那儿，而是因为**那里光线亮**。NVC 就是把注意力拉回真正要去的地方。

**表 0-1 · 两种语言的对照**

| 维度 | 疏离生命的语言（豺狗） | 非暴力沟通（长颈鹿） |
|---|---|---|
| 注意力焦点 | 谁对谁错、谁该受罚 | 什么需要没有被满足 |
| 对行为的表述 | 贴标签、做比较、一概而论 | 具体的、限定时空的事实 |
| 对情绪的表述 | "好/坏""被X" | 具体的情绪词 |
| 对诉求的表述 | 要求（不答应就指责惩罚） | 请求（不答应仍被尊重） |
| 对人的假设 | 对方是错的/坏的 | 对方在用自己的方式满足某种需要 |
| 目标 | 让对方服从 | 让各方需要都被满足 |

## 1 · 四要素引擎

把注意力聚焦在四个方面，它们是同一个引擎的四个要素 [第一章]：

**观察 → 感受 → 需要 → 请求**

原书完整示范：

> "菲利克斯，看到咖啡桌下的两团脏袜子和电视机旁边的三团脏袜子，我很生气，因为我希望在我们共用的空间里能多些整洁。你愿意把你的袜子放在你房间或放进洗衣机里吗？"

**两个方向，同一引擎**：表达自己（我观察…我感到…我需要…我请求…）与倾听他人（你看到…你感到…你需要…你希望…？）用的是同一组四要素。

**不是固定公式**：可因人、因文化、因情境调整，甚至无须借助言语。精髓在于对四个要素的**觉察**，不在于具体说了什么 [第一章]。

### 1.1 观察 — 不带评论

- 观察：清楚地观察哪些所见、所闻、所触正影响着我们的幸福，**不夹杂任何评论** [第三章]。
- NVC **不要求保持完全客观**，只要求**区分**观察与评论。它不鼓励一成不变、一概而论的陈述。
- 陷阱词：`总是 / 从不 / 每次 / 经常 / 又 / 依然`。
- 克里希那穆提："不带评论的观察是人类智力的最高形式。"

**表 1-1 · 评论 → 观察**

| ✗ 评论 | ✓ 观察 |
|---|---|
| 汉克是名糟糕的足球运动员 | 汉克在过去 20 场球赛中未进一球 |
| 我父亲是个好人 | 过去 25 年，我父亲将收入的十分之一捐给了慈善 |
| 你每次都把袜子乱扔 | 这周有三天，客厅地上都有你的袜子 |
| 他对我很冷漠 | 这周我两次跟他打招呼，他都没有回应 |
| 你从来不听我说话 | 刚才我说了三句，你一直在看手机 |

### 1.2 感受 — 区分感受与想法

- 真感受：具体的情绪词。**"好 / 坏"不合格**——"感觉挺好"可能是高兴、兴奋，也可能是如释重负 [第四章]。
- 伪感受：在"我感到 / 觉得"之后跟随**我、你、他、她、他们、它、像、好似**，通常都不是在表达感受 [第四章]。

**表 1-2 · 三类伪感受句式**

| 类型 | 例子 |
|---|---|
| "我感到" + 一句话 / "就像""好似" | "我觉得自己就像个失败者" |
| "我感到" + 人称 | "我觉得自己一直在被使唤" |
| "我感到" + 他人名称或名词 | "我觉得我的上司很爱控制人" |

**表 1-3 · 伪感受 → 真感受**

| ✗ 伪感受 | ✓ 替换 |
|---|---|
| 我感到被误解 | 我感到挫败 / 我很灰心 |
| 我觉得我就像嫁给了一堵墙 | 我感到孤单，想和你有更多情感上的交流 |
| 我很没用 | 想到我的能力，我感到怀疑 / 苦恼 |
| 你让我很失望 | 你昨晚没来，我很失望，因为我想要和你聊一些烦心事 |

完整词表（满足时 106 条 / 未满足时 136 条 / 伪感受黑名单 32 条）见 `references/feelings-needs-vocab.md`。

### 1.3 需要 — 为自己的感受负责

- 他人的言行**激发**我们的感受，但绝非**产生**这些感受的原因。感受源自我们如何看待他人的言行，以及当时的需要和期待 [第五章]。
- 需要是感受的根源。当我们评判、批评、分析他人时，实际上是在用疏离生命的方式**表达自己的需要**："你从不懂我" → 渴望被理解。
- 需要 vs 策略：**需要**不涉及某个人所采取的特定行动；**策略**涉及某个人可能采取的某个行动 [第十一章]。
  - "我需要结束这段婚姻" → 是策略。背后的需要可能是欣赏与理解。

**表 1-4 · 听到不中听的话的四种选择** [第五章]

| 选择 | 做法 | 结果 |
|---|---|---|
| 1 指责自己 | "哦，我应该更体贴一点" | 内疚、羞愧、压抑，自尊受损 |
| 2 指责他人 | "你没有资格这么说！" | 愤怒 |
| 3 **关注自己的感受与需要** | "我感到伤心，因为我渴望得到认可" | 触碰到生命能量，可导向行动 |
| 4 关注对方的感受与需要 | "你感到伤心，希望你的喜好得到照顾，是吗？" | 连结 |

**表 1-5 · 三类掩盖责任的语言** [第五章]

| 类型 | ✗ | ✓ |
|---|---|---|
| 非人称代词 | "手册有拼写错误，这让我非常生气" | "看到手册有拼写错误，我感到非常生气，因为我希望公司呈现专业的形象" |
| "我感到X，因为（别人）…" | "我感到愤怒，因为上司不守信用" | "当上司违背承诺，我感到愤怒，因为我原本希望用那个长假探望哥哥" |
| 只提他人行为 | "你没把食物吃完，妈妈感到失望" | "你没把食物吃完，妈妈感到失望，因为我希望你身体强壮、健康成长" |

**表 1-6 · 普世需要 7 大类** [第五章]

| 类别 | 英文名 | 说明 |
|---|---|---|
| 自主选择 | Autonomy | 选择自己的梦想、目标、方向 |
| 内外一致 | Integrity | 真诚、创造、意义、自我价值 |
| 庆祝 | Celebration | 庆祝生命的实现；纪念、哀悼与告别 |
| 相互依存 | Interdependence | 接纳、亲密、支持、信任、理解、被看见 |
| 精神交流 | Spiritual Communion | 美、和谐、秩序、平安、灵感 |
| 玩耍 | Play | 乐趣、欢笑、幽默、轻松 |
| 滋养身体 | Physical Nurturance | 空气、水、食物、休息、安全、免受伤害 |

> 原书只给出七个分类名，未列子项。上表"说明"为 NVC 通行实践补充，**非原书列举**。

### 1.4 请求 — 提出请求，丰盈生命

**表 1-7 · 请求的三条硬标准** [第六章]

| 标准 | ✗ | ✓ |
|---|---|---|
| 正向（说要什么） | "我希望你不要花那么多时间在工作上" | "我希望你每周至少有一个晚上在家陪我和孩子" |
| 具体可行 | "希望你有责任感""尊重我的隐私" | "进我房间前先敲门" |
| 此刻可回应 | "我希望你周六晚陪我看戏" | "你是否愿意周六晚和我一起去看戏？" |

- 负向请求的代价：人们搞不清到底要做什么，且容易引发抗拒。
- **请求 vs 要求**：判据是**对方拒绝后我们的反应**。指责 = 要求；同理 = 请求。
  - 原书示范：杰克说"我感到很孤单，你今晚能来陪我吗？"珍妮说"我今天很累"。杰克若回"你就是这样自私"，那是要求；若回"你的意思是你已经很累了，今晚需要休息？"，那是请求。
  - "在听见要求时，一个人通常只能看到两种选择：屈服或者反抗。"
- **选择请求不等于对方说"不"就放弃诉求**，而是先同理他为什么没有说"是"。
- **阐明目的**：若目的只是改变他人来谋求自己的利益，NVC 并不是适当的工具。它的意图是建立基于坦诚与同理心的关系。

### 1.5 表达后的两个确认动作

1. **请对方重述你的话** — 我们的本意和他人的理解有时是两回事。先说明目的：不是测试对方的聆听能力，而是核实自己是否表达清楚。
2. **请求诚实表达** — 明确想听哪一类回应：对方的感受及原因 / 对方的想法 / 对方是否愿意采取某个行动。

## 2 · 四个核心区分

**表 2-1 · 四区分总表**

| 区分 | 前者 | 后者 | 判据 |
|---|---|---|---|
| 观察 vs 评论 | 摄像机能拍到的事实 | 标签、推断、一概而论 | 出现"总是/从不"即为评论 |
| 感受 vs 想法 | 具体情绪词 | "好/坏"、"被X"、"我觉得你…" | "我感到"后接人称/像/好似即为想法 |
| 需要 vs 策略 | 普世、不指向特定行动 | 某个具体动作（离婚、加薪、陪我） | 带上"让某人做某事"即为策略 |
| 请求 vs 要求 | 不答应仍被尊重 | 不答应就被指责或惩罚 | 看拒绝后我们的反应 |

**为什么这四个区分是全书最硬的部分**：它们不是修辞偏好，而是能不能连结的分水岭。把评论当观察，对方听到的是批评；把想法当感受，对方不知道你到底怎么了；把策略当需要，谈判就锁死在一个动作上；把要求当请求，对方要么屈服要么反抗。

## 3 · 同理倾听

### 3.1 同理的本质

同理 = 以尊重的态度了解他人的体验。**"不去做什么，只是在那里"** [第七章]。

- 同理 ≠ 同情、≠ 头脑上的理解、≠ 给建议 / 安慰 / 分析。
- "同理的核心是'临在'——全然地与他人以及他们当下的体验同在。"
- 原书教训：女儿说"我丑得像头猪"，父亲立刻安慰"你是上帝带到这个地球上最美丽的礼物"，女儿摔门而去。她要的只是："你对你今天的样子感到失望是吗？"
- **在给建议或安慰前，先核实那是不是对方想要的。**

### 3.2 妨碍同理的行为（原书列举）

| 行为 | 典型话术 |
|---|---|
| 给建议 | "我认为你应该……" |
| 比惨 | "这算不了什么。你听听我曾经经历过的。" |
| 说教 | "如果你这样做……会变成积极的体验。" |
| 安慰 | "这不是你的错，你尽力了。" |
| 讲故事 | "这让我想到曾经……" |
| 摆脱感受 | "高兴一点儿，不要这么难过。" |
| 同情 | "哦，你真是可怜……" |
| 询问 | "这种情况是什么时候开始的？" |
| 解释 | "我本来想打电话给你，可是……" |
| 纠正 | "事情不是这样的。" |

### 3.3 同理操作四步

1. **听四要素** — 无论对方用什么言辞，只听他的观察 / 感受 / 需要 / 请求。
   - **关注他的需要，而非他对你的看法**：用"你不高兴，是因为你需要…？"而非"你是在生我的气吗？"（后者暗示是你导致的）。
2. **复述** — 用探询式提问反馈，便于对方更正。
3. **持续同理** — 充分同理的判据：对方放松 / 自己不再紧绷 / 对方安静下来。不确定就问："还有什么是你想要说的吗？"
4. **对方抗拒时** — 他说"你别跟我玩心理学那套"，继续同理这句背后的需要。

### 3.4 当对方沉默或说"不"

- **沉默**：同理对方透过沉默表达的感受和需要，不擅自往坏处想 [第八章]。
- **"不"**：不是拒绝，而是有某个需要挡住了答应你。听见那个需要，对话就能继续 [第八章]。

### 3.5 同理心的力量：五个场景 [第八章]

| 场景 | 要点 |
|---|---|
| 疗愈作用 | 有人真的听到你的心声、不评头论足、不想改变你——原本无解的问题因此有了办法 |
| 与袒露脆弱的能力 | 越能与他人连结，越不害怕袒露自己；不愿展现脆弱常是因为想显得"强悍" |
| 化解危险 | 紧张情态下同理可以避免潜在的暴力 [本仓库修正：正在发生的人身侵害优先脱离与报警，同理只作争取时间的辅助] |
| 乏味的对话 | 一个字都听不下去时就是打断的时机；打断的目的不是让自己发言，而是帮对方连结到自己的需要 |
| 面对沉默 | 同理沉默背后的感受与需要，或说出自己的感受并询问怎样能让对方觉得安全 |

### 3.6 无法同理时的三个选项 [第七章]

"我们无法把自己没有的东西给予他人。"

1. **同理急救 / 自我同理** — 停顿，聆听自己的内心。
2. **非暴力呐喊** — 不带指责地大声说出当下的痛苦与迫切需要：
   "我现在很难受！真的不想来管你们打架的事情，我只想要安静一会儿！"
3. **离开现场** — 前两者都无效时，暂时离开，获得同理后再回来。

## 4 · 爱自己

### 4.1 哀悼与自我宽恕 [第九章]

- 自责的常见形式："笨蛋！""你总是把事情搞砸！""真自私！"——这只会陷入自我憎恨，无法从失误中学习。
- "应该"这个词充满暴力，它暗示别无选择；人天生抗拒被"应该"支配，不论来自外在强权还是内在暴君。

**哀悼（mourning）**：觉察自我评判 → 停下来问"我这样指责自己，是因为什么需要没有得到满足？" → 充分连结那个未被满足的需要，以及由此引发的感受。
- "哀悼，让我们不再以指责或怨恨自己的方式来经验后悔，而是帮助我们从中学习。"
- 关键区分：**难过、挫败、失望、恐惧、悲伤**是与生俱来的感受，推动我们去满足需要；**内疚、羞愧、压抑**会切断我们与自己的连结。

**自我宽恕**：问"我当时那样做，是要满足什么需要呢？"——人的行为都是为了满足需要所做的尝试。
- 带着同理心拥抱两个"自己"：懊恼的自己 + 当初那样做的自己。

### 4.2 "不得不"转化为"我选择" [第九章]

1. 列出无趣却又认为不得不做的事。
2. 在每件前面加"**我选择做……**"。
3. 补全"**我选择做……因为我想要……**"，连结背后的需要。

原书结果（本仓库缩写）：马歇尔发现自己写临床报告的唯一动机是收入，于是停写；继续开车送孩子上学，因为看见自己重视教育品质——同样是送，心态完全变了。

### 4.3 情绪自由三阶段 [第五章]

| 阶段 | 信念 | 代价 | 出路 |
|---|---|---|---|
| 情绪的奴隶 | 我要为他人的感受负责 | 把亲近的人当负担 | 转向关注自己的需要 |
| 面目可憎 | "这是你的问题，不关我事" | 关系受损，仍未学会非奴役式互动 | 已是进步，需学会尊重他人的需要 |
| 情绪的主人 | 我为自己的感受负责，同时明白牺牲他人也无法满足自己 | — | 出于慈悲而非恐惧、内疚、羞愧地回应他人 |

### 4.4 觉察行为动机的 6 类来源 [第九章]

| 动机 | 要点 |
|---|---|
| 为了钱 | 金钱不是"需要"，而是满足某个需要的策略之一 |
| 为了得到他人的认可 | 外在奖励；若行动只为丰盈生命，人们自然会来欣赏我们 |
| 为了免受惩罚 | 为免罚而做，心怀抵触 |
| 为了避免羞愧 | 只因不想被自己抨击而做的事，通常以厌恶告终 |
| 为了免于内疚 | "如果我不做，别人会失望"——苦不堪言 |
| 为了履行职责 | "应该/不得不/必须"驱动的是义务感，而非与需要的连结 |

**核心判据**：出于对生命纯粹的爱而行动，即使辛苦也乐在其中；出于恐惧、内疚、羞愧、义务或职责，即使有趣的事也会失去乐趣。原书立场：**不做任何没有乐趣的事**。

### 4.5 用非暴力沟通取代诊断 [第十三章]

不再探讨"对方有什么问题"，转而关注：

1. 他现在的感受是什么？
2. 他需要什么？
3. 面对他，我有什么感受？
4. 我的感受反映了什么需要？
5. 我想请求他做什么使他过得更幸福？

辅导关系的目标：创造**真诚、坦率和双向**的关系，而不是保持情感距离、诊断对方，或摆出高高在上的专业姿态。

## 5 · 愤怒与冲突

### 5.1 刺激 vs 原因 [第十章]

- 他人的行为是**刺激**，不是**原因**。
- 愤怒产生于四种选择中的第 2 种：把错误归咎于他人。那一刻我们在扮演上帝，评断他人该受罚。
- **愤怒 = 未满足需要的报警器**。所有怒气背后都有一个没被满足的需要，以及一个切断了与需要连结的指责性想法。
- 助长混淆的语言："你让我生气""你这样做伤害了我"。

### 5.2 表达愤怒的四个步骤 [第十章]

1. **停下来，深呼吸** — 不指责不惩罚，只是保持安静。
2. **看看我们有哪些评判性的想法** — "这不公平""他不尊重人""她这是种族歧视"。
3. **与我们的需要连结** — 评判背后是什么需要：平等、尊重、连结、安全…
4. **表达我们的感受和未被满足的需要** — 怒火此时已转化为感受与需要。

第 3、4 步之间通常要**先同理对方**：对方还在情绪里，就听不进我们的感受和需要。

### 5.3 需要 vs 策略 vs 分析 [第十一章]

- **分析**：诊断对方的问题（"你无动于衷""你没有责任感"）——实质是用悲剧方式表达自己未被满足的需要，**会被听成批评**，把双方推向战争。
- 训练自己：无论对方用沉默、否定、评判、肢体语言还是请求表达，都听见背后的需要（常靠猜测，再求证）。

### 5.4 化解冲突五步骤 + 调解七要点

**五步骤** [第十一章]：
1. 表达自己的需要。
2. 不论对方说什么，找出他们真正的需要（若说的是想法/评判/分析，继续往下找）。
3. 确认彼此都准确理解了对方的需要。
4. 尽可能同理对方。
5. 用**正向的、此刻可回应的行动语言**提出化解策略。

**调解七要点** [第十一章]：明确角色与信心 · 冲突与你无关 · 急救式同理 · 追踪进度（可用白板记录）· 聚焦当下 · 推动对话进程（可用角色扮演）· 勇于打断。

**第一性原则**：连结优先于解决方案；目标**满意，而非妥协**。

**两个关键技巧**：
- **痛苦阻碍聆听 → 先同理舒解痛苦**。
- **行动语言**：把"聆听""让我做自己"换成能被摄像机拍到的动作（如"请你复述我刚才说的"）。

### 5.5 保护性 vs 惩罚性强制力 [第十二章]

| | 保护性强制力 | 惩罚性强制力 |
|---|---|---|
| 目的 | 防止人受伤或受到不公待遇 | 让"做错事"的人吃苦头、后悔、改变 |
| 假设 | 对方出于无知，需要**教育** | 对方是坏的或邪恶的，需要**惩罚** |
| 例 | 一把抓住要冲上马路的孩子 | 打孩子、"你真是太丢脸了" |

**惩罚的种类**：体罚 / 心理惩罚（贴标签羞辱）/ 剥夺关爱（限制零花钱、取消权利——"拿走关爱或尊重，是最强有力的威胁"）。

**惩罚的代价**：注意力落在后果上而忽略事情本身的价值；削弱自尊；磨灭善意。

**惩罚的局限**：两个提问——① 我希望他做出什么改变？② **他会因为什么原因照我的话做？** 常见的实际动机是服从权威、避免惩罚，而非爱整洁或体谅。

## 6 · 感激

### 6.1 为什么评判式赞美是问题 [第十四章]

"你真棒""你真体贴"属于疏离生命的沟通——说话人**以裁判者自居**，并未传递其内心。"我将所有评判——无论正向还是负向——都定义为疏离生命的沟通。"

- 表扬的短期效果不长久：**一旦人们发现表扬是为了控制，生产力就会下滑**。

### 6.2 感激三要素 [第十四章]

1. **对方做了什么**增进了我们的福祉（具体行为，不是标签）
2. 我们**哪些需要**因此得到满足
3. 因此引发了**什么愉悦感受**

> "当你[做了什么]，我感到[感受]，因为我[哪些需要]得到了满足。"

唯一意图是**庆祝**，不为索取任何回报。

### 6.3 如何接收感激

两个极端都断了连结：**自负**（觉得自己高人一等）与**故作谦虚**（"哦，那没什么"）。

带着同理心接收：聆听自己做了什么增进了对方的福祉、满足了什么需要、引发了什么感受，与对方一起庆祝。

## 10 · 常见误解 FAQ [本仓库扩展]

**Q1 NVC 是不是要我一直憋着、不能生气？**
不是。NVC 要求的是**充分表达愤怒**，而不是压抑它。路径是：停下 → 看见自己的评判性想法 → 连结需要 → 表达感受与需要。

**Q2 是不是永远不能评判别人？**
要区分**价值判断**与**道德评判**。珍视诚实、自由、和平是价值判断，可以保留；指责不符合这些价值观的人是道德评判，需要替换成"我感到…因为我需要…"。

**Q3 对方完全不配合怎么办？**
NVC 不要求对方也懂它。选择请求意味着先同理对方为什么没有说"是"，而不是说服他必须答应。若对方长期处于强烈情绪中，先给足同理——痛苦会阻碍聆听。

**Q4 这样说话是不是很假、很机械？**
机械套用四要素而无连结意图，本身就是反模式。四要素是觉察，不是句式。

**Q5 NVC 是不是不能拒绝别人？**
可以拒绝。关键是把"不"背后的需要说出来，而不是把拒绝包装成指责。

**Q6 在职场/权力关系里用，会不会显得软弱？**
原书观察到相反的结果：袒露脆弱（如管理层承认"再次提出这个计划，我感到非常惶恐"）反而改变了对方的立场。同时要注意，处于权力强势一方时，请求更容易被听成要求，需要额外说明意图。

**Q7 对方在施暴，我也要同理他吗？**
**不要。** 家暴、性侵、儿童虐待、自伤自杀等危机场景优先处理安全，不做话术改写，不要求受害方先同理施害者。见附录 D。

**Q8 这个方法能用来让对方照我说的做吗？**
不能。若目的只是改变他人来谋求自己的利益，NVC 并不是适当的工具 [第六章]。

## 附录 D · 安全边界（摘要）

**触发信号**
- 人身安全：家暴、性侵、儿童虐待、施暴者在场
- 自伤自杀：表达不想活、交代后事、描述具体计划、已实施自伤

**处置顺序**：停止常规话术流程 → 不要求同理施害者 → 先稳定不分析 → 安全判断 → 求助资源 → 交还选择权。
