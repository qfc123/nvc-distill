## 四要素拆解

| 要素 | 内容 | 自检 |
|---|---|---|
| **观察 O** |  | 摄像机能拍到吗？有没有"总是 / 从不 / 每次 / 经常 / 又 / 依然"？（用于定性即为评论） |
| **感受 F** |  | 是具体情绪词吗？有没有"好/坏"、"被X"？ |
| **需要 N** |  | 普世吗？有没有指向某个具体动作（那是策略）？ |
| **请求 R** |  | 正向？具体可行？此刻可回应？ |
