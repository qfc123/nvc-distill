# 交付模板 · 冲突调解工作簿（D3）

用法：用于复盘或调解一次冲突，落盘为 `.md` 后再把文件展示给用户（WorkBuddy 用 `present_files`）。

> **前置检查（A / B / C 三类任一命中都不要用本模板）**：
> - 家暴、性侵、儿童虐待、性胁迫
> - 自伤自杀风险
> - **C 类任一子类命中都不要用本模板**：**C1** 控制与虐待（长期贬低、经济控制 / 经济虐待、隔绝）/ **C2** 权力不对等（上下级、师生、医患）/ **C3** 诊断、用药与物质依赖（若出现自伤自杀信号按 B 类处理）——这类关系里没有"各让一步"的中立位置，把它当冲突来调解等于承认双方责任对等。
>
> 命中任一 → **不要使用本模板**，转 `references/safety-boundaries.md`。
